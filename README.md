# Booksky📚
Booksky is a minimal, interactive book manager built with HTML, CSS, and JavaScript. It allows users to add and remove books dynamically, each with a title, author, and description.

⚙️ Features- 
Dynamic book creation with popup form,
Instant deletion of book entries,
Clean, responsive UI with custom styling

🛠 Tech Stack 
• HTML
• CSS 
• JavaScript
